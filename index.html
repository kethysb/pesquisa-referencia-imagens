Tipo 01: Baixa Densidade (Capa / Gancho)

Quando usar: Para capas de carrosséis e posts de impacto de topo de funil.
Regra: Apenas 1 manchete curta (3 a 8 palavras) + 1 subtítulo. Fotografia ocupa 65% a 75% da área com respiro amplo.

// Exemplo de Estrutura de Código { "tipo": "baixa_densidade", "h1": "Seu patrimônio exige estratégia.", "sub": "Planejamento sucessório com segurança.", "foto_layout": "envelope_diagonal" }

Tipo 02: Alta Densidade (Grid Modular Suíço)

Quando usar: Para lâminas de meio de funil, checklists, 4 pilares ou decomposição de valores.
Regra: Divide o canvas em 4 caixas simétricas (2x2) com ícones monocromáticos e números.

// Exemplo de Estrutura de Código { "tipo": "grid_modular_4_caixas", "h1": "4 Motivos Para Criar uma Holding", "cards": [ {"num": "01", "titulo": "Economia Tributária"}, {"num": "02", "titulo": "Blindagem de Bens"} ] }

Como Funciona o Extrator Automático (`extrair_metricas.py`)

O script lê a imagem de referência selecionada e gera automaticamente o arquivo design_tokens.json com a paleta exata em HEX e as dimensões calculadas:

# Comando de terminal para extrair métricas de qualquer imagem: python 03_extrator_metricas_design/extrair_metricas.py <caminho_imagem> design_tokens.json # Saída gerada automaticamente: { "dimensoes_originais": { "largura": 1081, "altura": 1351 }, "formato_detectado": "Feed Vertical 4:5 (1080x1350)", "safe_zone_instagram_feed_px": { "largura": 1080, "altura": 1080, "offset_topo_px": 135 }, "paleta_hex": { "fundo_canvas": "#F8F9F4", "acento_principal": "#D4D2CB", "texto_dominante": "#21302F" }, "css_variables_snippet": ":root {\n --canvas-bg: #F8F9F4;\n --brand-accent: #D4D2CB;\n --text-main: #21302F;\n}" }
